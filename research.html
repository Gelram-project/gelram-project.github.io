What is GEL RAM?

GEL RAM is a source-available research project written in Rust. It investigates deterministic representation of information in memory, using fixed Q8 records, integrity verification and recovery tests. Its public repository exposes tools and reproducible test harnesses rather than a general-purpose LLM.

Research scope and public claims checked against the project's claim registry and evidence record. Updated 10 November 2026.

What is the Q8 memory record?

The public Q8 representation uses 1,024 one-byte phase values and a 128-byte activity mask, totaling 1,152 bytes per record. Four reversible views of that one record can be compared bit-for-bit against reference copies. A view is a transformation of the same stored content, not an independent source of information. This alone neither proves semantic search nor faster AI inference.

What are the integrity and persistence claims?

The public demonstrations check byte-exact recovery, SHA-256-based detection of modified data, and recovery of acknowledged snapshots after process termination. These are bounded software checks. They do not demonstrate source truth, confidential encryption, a physical power-cut guarantee, or power-loss safety on all filesystems.

Is GEL RAM an LLM or working chatbot?

No such conclusion follows from the public checkout. The project's ambition includes free conversation in Polish and English with source-grounded answers and meaningful abstention. The public repository distinguishes that goal from executable checks. There is no public private-knowledge bank or private conversational engine included.

How can I verify GEL RAM on my computer?

Use Git, rustup and an environment with enough resources to build the public workspace. The following commands select the documented v0.9.0 tag and produce a report:

git clone https://github.com/Gelram-project/gel-ram.git
cd gel-ram
git checkout v0.9.0
rustup toolchain install 1.85.0 --profile minimal
cargo fetch --locked
cargo run --locked --offline -p xtask -- witness ../gel-check

The output directory must not exist and must be outside the checkout. The runner reports PASS, FAIL or SKIPPED, including Unix-only process-kill steps. Inspect the output for sensitive data before submitting it. Read the complete instructions and independent evidence request.

GEL RAM po polsku

GEL RAM jest projektem badawczym w Rust dotyczącym reprezentowania informacji w pamięci. Udostępniony kod pozwala sprawdzać dokładność odczytu rekordów Q8, kontrolę zmian danych i odzyskiwanie stanu po przerwaniu procesu. Cztery widoki rekordu nie oznaczają czterech niezależnych kopii informacji.

Pełna dwujęzyczna konwersacyjna sztuczna inteligencja oraz obliczenia w strukturach sprzętowej pamięci pozostają celami badawczymi. Publiczny kod i instrukcje testów pozwalają niezależnie weryfikować wyraźnie opisane własności.
