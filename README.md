# GEL RAM project discovery site

This repository publishes a static, crawlable introductory page at
<https://gelram-project.github.io/>.

The page links to the canonical [GEL RAM public Rust source repository](https://github.com/Gelram-project/gel-ram)
and to the detailed [Cloudflare Pages project site](https://gel-ram.pages.dev/).
It provides a concise evidence summary and boundaries, reproducible check instructions,
English and Polish project descriptions, JSON-LD metadata, Open Graph tags,
`robots.txt`, `sitemap.xml`, and a voluntary `llms.txt` resource.

The introductory page is an additional discovery entry point, not a replacement
for the full project website or its source of truth. The public source is
noncommercial source-available code; do not describe it as OSI-approved open source.

## Maintenance

When changing public claims or test instructions, verify their precise scope in
the source repository's `docs/CLAIMS.md` and `docs/REPRODUCE.md`.
Never list private implementation claims as publicly verified. Keep the sitemap's
`lastmod` aligned with substantive updates to `index.html`.

Publishing a page does not guarantee search-engine indexing. Search Console or
Bing Webmaster Tools ownership verification and indexing diagnostics require the
site owner's credentials.
