GEL RAM

Research into knowledge represented as fixed Q8 records in memory, with exact read-back, source integrity and reproducible public tests.

The public repository demonstrates bounded byte-level and persistence properties. A free-form Polish/English text AI and hardware-level memory computation are goals, not established results. The public repository does not include the private implementation or knowledge bank.

What the public code tests

One record, four views

A 1,152-byte Q8 record: 1,024 phase bytes and a 128-byte activity mask. Four reversible views read the same record exactly; they are not four independent memories.

Exactness and integrity

Literal bytes are read back through all views; modified data is refused under an independently held SHA-256 pin. This does not verify the truth of source content.

Process-kill recovery

Public test runners interrupt writing processes and check acknowledged state and recovery. This is not a physical power-loss guarantee.

Read the project research FAQ, the claim registry, public evidence and noncommercial source-available license before interpreting any performance claim.

Reproduce the public checks

The public project provides a versioned Rust toolchain and an offline witness runner. Install Git and rustup, then run:

git clone https://github.com/Gelram-project/gel-ram.git
cd gel-ram
git checkout v0.9.0
rustup toolchain install 1.85.0 --profile minimal
cargo fetch --locked
cargo run --locked --offline -p xtask -- witness ../gel-check

Use a new output directory outside the checkout. Share the resulting WITNESS.txt only after reviewing its contents. A second machine's results can be submitted to independent reproduction issue #20. Follow the full witness guide.
